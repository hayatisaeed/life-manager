# Life Manager

A private, offline-first life manager for **macOS, Windows, Android and the
web** (iOS later). It covers tasks and planning, habits and routines, focus
and time tracking, money, health and journaling, notes and flashcards, a
personal CRM for the people in your life, and life admin, with an optional AI
assistant on top.

- **Your data stays yours.** Everything is stored on your devices. Sync is
  optional and goes through **your own private GitHub or GitLab repository**.
  Everything pushed there is end-to-end encrypted, so the host only sees
  ciphertext.
- **No server, no account, no telemetry.**
- **English and Persian (RTL), Gregorian and Jalali calendars,
  multi-currency.**
- **Light and dark modes**, with a minimal, modern design.

**Status:** planning is complete and implementation hasn't started. See
[docs/STATUS.md](docs/STATUS.md).
