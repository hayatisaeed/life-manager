# Life Manager

A private, offline-first life manager for macOS, Windows, Android and the web.
It covers tasks, planning, habits, focus, money, health, notes, people (a
personal CRM) and life admin, with an optional AI assistant.

Data lives on your devices. Sync is optional and goes through a private git
repository you control. Everything pushed there is end-to-end encrypted.
